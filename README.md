# Lógica e algoritmos com JavaScript

Coleção de exercícios de programação executados no terminal.

## 📌 Funcionalidades

- Prática de variáveis e condicionais.
- Exercícios com laços de repetição.
- Entrada de dados pelo terminal.

## Tecnologias

JavaScript, Node.js e prompt-sync.

## 🚀 Como executar

```bash
git clone https://github.com/daviddevdias/logic-and-algorithms-js.git
cd logic-and-algorithms-js
npm ci
node aula3.js
```

Substitua `aula3.js` pelo exercício desejado. Os arquivos `aula*.js` e `trabalho*.js` registram diferentes etapas de estudo.
